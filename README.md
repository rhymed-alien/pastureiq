# PastureIQ

A free, weather-driven decision-support tool for small New Zealand sheep and beef farmers.
It combines live weather data, pasture carrying-capacity estimates, and livestock market
signals into simple, plain-language guidance on pasture and stock buy/sell timing.

**Status:** In development — capstone project, due October 2026

## The problem
Small NZ farmers are time-poor and often make decisions on gut feel. The gap between
average and top-performing farms is decision quality, not farm size. This tool aims to
help close that gap using free, open, scientifically-grounded data.

## Target regions
- South Waikato / King Country hill country
- South Taranaki / northern Whanganui hill country
- West Auckland lifestyle blocks (edge case)
